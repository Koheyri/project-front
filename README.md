# Project Front

Клиентская часть веб-приложения на HTML/CSS/JS для взаимодействия с backend-сервисами через REST API.

## Описание проекта

Проект предоставляет пользовательский интерфейс для взаимодействия с backend-сервисами. Реализована интеграция Frontend и Backend через AJAX-запросы к REST API.

**Технологический стек:**
- HTML5
- CSS3
- JavaScript (Vanilla)
- Maven (для сборки)

## Цель проекта

| Аспект | Описание |
|--------|----------|
| Что решает | Предоставление пользовательского интерфейса для взаимодействия с backend-сервисами |
| Для кого | Конечные пользователи веб-приложения; демонстрация интеграции Front ↔ Back |

## Функциональные требования

### User Stories

| ID | Описание | Приоритет |
|----|----------|-----------|
| US-1 | Интуитивный интерфейс для удобной работы с приложением | High |
| US-2 | Отправка форм для взаимодействия с backend | High |
| US-3 | Получение обратной связи от системы о результате действий | High |
| US-4 | Чистая структура HTML/CSS для поддержки кода | Medium |

### Use Cases

- Просмотр страниц
- Заполнение форм
- Отправка запросов к API
- Получение и отображение результатов
